# Credit Scoring & Risk Analysis in Lending

An end-to-end credit risk analysis project analyzing 20,000 synthetic loan applications across seven UK regions.

## Project Structure
* `credit_pipeline.py`: Automated Python ETL pipeline (Extract, Transform, Validate, Save).
* `cleaned_credit_data.csv`: Validated dataset with engineered risk tiers and debt-to-income metrics.
* `phase2_sql_queries.sql`: SQL queries analyzing approval rates, default risk, and loan sizes.
* `dashboard.html`: Interactive browser-based risk desk dashboard.
* `Credit_Scoring_Project_Report.docx`: Complete project report and methodology.

## Technologies Used
* Python (Pandas, SQLite3)
* SQL
* HTML5 / JavaScript (Chart.js)
